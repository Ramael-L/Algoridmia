 Algoritmia - Sesión 3

Ejercicios realizados en **PSeInt** para practicar ciclos y resolver problemas.

Ejercicios

1. **Caracol:** calcular los días para salir de un pozo.
2. **PIN:** validar una contraseña con 3 intentos.
3. **Parqueadero:** contar carros y sumar pagos.
4. **Calificaciones:** calcular promedios y notas.
5. **Pirámide:** dibujar asteriscos usando ciclos.
6. **Restaurante:** calcular una factura con subprocesos.

 Lo que aprendí

Aprendí a utilizar ciclos `Para`, `Mientras` y `Repetir`, además de contadores, acumuladores y subprocesos.

 Cómo ejecutar

Abrir los archivos `.psc` en PSeInt y presionar **Ejecutar**.
