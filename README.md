# Algoritmia con PSeInt

My Learning with PSeInt

 About this project

This project is about my first steps in programming with PSeInt. I learned how to solve simple problems using algorithms.

 How I learned

I started with easy exercises, like reading a name, calculating age in days, and finding the average of grades. Later, I practiced conditions with registration and parking payment exercises. I also used loops to solve problems with a snail, a PIN, grades, and a star pyramid.

 Key topics

- Variables: save information.
- Read and Write: get and show information.
- If and Else: make decisions.
- For, While, and Repeat: repeat instructions.
- Counters and accumulators: count things and add values.
- Nested loops: use one loop inside another.

 What was difficult for me

The hardest part was understanding loops. Sometimes I did not know which loop to use. The star pyramid was also difficult because it uses loops inside other loops. I need more practice with these topics.

 Conclusion

PSeInt helped me understand programming logic. I am still learning, but now I can create simple algorithms and understand my code better.

## Folder structure / Organización

- [semana-1](semana-1/): variables, inputs, calculations and diagrams (variables, entradas, cálculos y diagramas).
- [semana-2](semana-2/): conditions and validation (condicionales y validaciones).
- [semana-3](semana-3/): loops, counters, accumulators and nested loops (ciclos, contadores, acumuladores y ciclos anidados).

Each folder keeps the original PSeInt source files (.psc) and its documentation or flowcharts where available.
